\begin{abstract}
   Modern Internet Service Provider (ISP) and enterprise networks suffer from transient micro-bursts and rapidly fluctuating traffic demands. Traditional traffic engineering approaches such as Equal-Cost Multi-Path (ECMP) rely on static hash-based packet distribution. While mathematically simple these methods are blind to real-time network states and often hash heavy elephant flows onto the same physical links causing severe bottlenecks and buffer bloat. This paper evaluates Deep Reinforcement Learning (DRL) algorithms specifically Deep Q-Network (DQN) and Proximal Policy Optimization (PPO) for proactive load balancing across wide-area topologies. Our agents are trained to dynamically shift flows across candidate paths to minimize queue congestion and maximize throughput. Tested on unseen topologies from the Internet Topology Zoo PPO and DQN substantially outperformed the ECMP baseline during highly variable traffic bursts. The findings indicate that PPO provides a more stable convergence profile and more robust generalization across traffic stress tests compared to both DQN and traditional static heuristics.
\end{abstract}

\section{Introduction}

Network traffic engineering aims to optimize performance by dynamically routing data across available infrastructure. With the exponential growth of cloud computing, video streaming and IoT applications wide-area networks are experiencing unprecedented levels of traffic volume and volatility. Traditional routing protocols such as OSPF and BGP operate primarily on shortest-path metrics which can easily lead to congestion on optimal links while alternative paths remain underutilized.

To address this Equal-Cost Multi-Path (ECMP) was introduced to distribute traffic across multiple paths of equal cost using static hashing algorithms based on packet headers. While ECMP provides a rudimentary form of load balancing it is inherently reactive and stateless. It cannot detect micro-bursts or asymmetric flow sizes frequently resulting in hash collisions where multiple massive elephant flows are mapped to the exact same bottleneck link degrading overall network throughput and inflating queue latency.

The advent of Software-Defined Networking (SDN) has separated the control plane from the data plane enabling centralized and programmable network management. This paradigm shift has paved the way for advanced machine learning techniques to be applied directly to network traffic control. Specifically Deep Reinforcement Learning (DRL) offers a compelling alternative to static heuristics by allowing an intelligent agent to continuously interact with the network environment observe real-time telemetry (such as link utilization and queue depth) and dynamically adjust routing weights to optimize a long-term reward function.

In this research we comprehensively evaluate two prominent DRL algorithms. These are Deep Q-Network (DQN) and Proximal Policy Optimization (PPO). We evaluate them for the task of proactive load balancing. We hypothesize that DRL agents operating within an SDN controller framework can learn near-optimal routing policies that significantly outperform ECMP particularly under adversarial burst traffic conditions.

Finally Section 6 concludes the paper and discusses avenues for future work.

\section{Related Work}

The application of Reinforcement Learning to network routing has garnered significant attention in recent years. Early approaches utilized tabular Q-learning to route packets but these methods struggled to scale due to the curse of dimensionality inherent in large network state spaces.

The introduction of Deep Q-Networks (DQN) enabled RL agents to handle high-dimensional continuous state spaces by approximating the Q-value function with deep neural networks. Subsequent networking research applied DQN to optimize OSPF link weights and perform flow-level routing in SDN environments. However DQN is an off-policy value-based method that can suffer from training instability and overestimation bias particularly in highly dynamic environments like network traffic control.

To address these instabilities policy gradient methods such as Proximal Policy Optimization (PPO) have been explored. PPO directly optimizes the policy network while restricting the size of policy updates via a clipped objective function ensuring monotonic improvement and preventing catastrophic performance collapse during training.

Despite these advancements a significant research gap remains regarding the zero-shot generalization capabilities of these algorithms. Many existing studies train and evaluate DRL agents on the exact same network topology failing to demonstrate whether the learned routing policies can generalize to entirely novel network architectures. This study bridges this gap by rigorously evaluating the generalization performance of DQN and PPO on unseen topologies sourced from the Internet Topology Zoo under highly volatile traffic conditions.

\section{Methodology}

\subsection{System Architecture and Environment}

We modeled the network load balancing problem as a continuous-time Markov Decision Process (MDP) and developed a custom simulation environment using the Gymnasium framework. The environment accurately simulates link capacities, queue buffers and dynamic traffic flows across arbitrary network graphs.

For our physical network models we utilized the Internet Topology Zoo which is a comprehensive database of real-world ISP network topologies. The raw GraphML files were preprocessed to extract adjacency matrices and precompute the K-shortest paths between all source-destination pairs using Yen algorithm.

\subsection{Markov Decision Process Formulation}

The MDP is defined by the tuple $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$.

\textbf{State Space}: The state vector provides the agent with a holistic view of the real-time network conditions. It is a 250-dimensional continuous vector comprising:
1. Link Utilization (100 features): The current throughput ratio of the top 100 most critical links.
2. Queue Occupancy (100 features): The buffer depth of the corresponding switch interfaces indicating localized congestion.
3. Flow Demands (50 features): The instantaneous bandwidth requirements of the largest active flows.

\textbf{Action Space}: The agent controls the routing policy by outputting continuous load-balancing weights. For each active flow the action vector dictates the proportion of traffic to be routed across each of the K-shortest paths. In the case of DQN the action space is discretized into discrete routing choices whereas PPO operates directly on the continuous probability distribution.

\textbf{Reward Function}: The reward function is the critical signal that guides the agent learning process. We designed a composite reward function that balances throughput maximization with latency minimization. We heavily penalize queue overflow (congestion) while rewarding high overall link utilization (throughput). The exact mathematical formulation ensures that the agent cannot simply drop packets to achieve zero congestion.

\subsection{Deep Reinforcement Learning Algorithms}

We implemented both DQN and PPO using the Stable-Baselines3 library.

\textbf{DQN}: The DQN agent utilizes a Multi-Layer Perceptron (MLP) architecture with three hidden layers of 256 units each. It employs a replay buffer of size 100000 to break temporal correlations in the training data and a target network that is soft-updated to stabilize the temporal difference targets.

\textbf{PPO}: The PPO agent also utilizes an MLP actor-critic architecture. It collects trajectories of length 2048 before performing optimization steps. The clipping parameter is set to 0.2 and the entropy coefficient is set to 0.01 to encourage exploration and prevent premature convergence to sub-optimal deterministic policies.

\section{Experiments and Results}

\subsection{Experimental Setup}

Training was executed on an NVIDIA RTX 3060 GPU. To ensure the statistical significance of our findings both agents were trained independently across 5 distinct random seeds (42, 100, 2024, 777 and 1337).

Following training the agents were subjected to a zero-shot generalization test. They were deployed on entirely unseen topologies and evaluated against the traditional ECMP baseline under three distinct adversarial traffic profiles. These profiles are moderate, burst and congestion traffic modes.

\section{Conclusion}

This study conclusively demonstrates that Deep Reinforcement Learning represents a viable high-performance alternative to traditional static routing heuristics like ECMP. By training DQN and PPO agents in a realistic topology-agnostic environment we proved that AI-driven SDN controllers can proactively balance network loads successfully avoiding micro-burst bottlenecks and minimizing queue latency.

Our results highlight Proximal Policy Optimization (PPO) as the premier algorithm for this task owing to its exceptional training stability, continuous action space capabilities and robust zero-shot generalization to unseen network topologies. Future work will investigate the deployment of these models in distributed multi-agent frameworks to mitigate the telemetry propagation delays inherent in centralized SDN architectures.
